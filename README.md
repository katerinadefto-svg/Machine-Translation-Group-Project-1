# Machine Translation Project 1
This repo contains the code that implements the first group assignmet of the course Neural Machine Translation, concerning the cleaning of a corpus and the selection of a training sample.

## Step 1
Download the provided datasets from our shared gdrive folder and save them to the root of the project.
- `ParaCrawl_subset.el-en.el` contains the greek sentences
- `ParaCrawl_subset.el-en.en` contains the aligned english translations

We also recommend creating a virtual environment using [uv](https://docs.astral.sh/uv/pip/environments/)
```
uv venv
uv init
```
