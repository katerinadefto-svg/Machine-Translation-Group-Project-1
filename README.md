# Machine Translation Group Project

## Using Google Translate
Needed steps
- create a google cloud project
- enable billing
- enable cloud translation API
- generate an API key
See example of translation in `google_translate.py`

## Using DeepL
Needed steps
- create a developer account
- get your free API key
See example of translation in `deepl_translate.py`

## Using Azure Translate
Needed steps
- create Azure account
- in the Azure portal create a Translator resource (F0 pricing tier for the free quota)
- get the API key and the Location/Region of the resource
See example of translation in `azure_translate.py`
